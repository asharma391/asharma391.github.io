# Arjun Sharma

Personal website: https://asharma391.github.io/

A single HTML page with inline CSS. No JavaScript, dependencies, or build step.

## Edit

Edit `index.html` and push to `main`. GitHub Pages publishes from the root of that branch. `.nojekyll` disables Jekyll processing.

## Preview locally

Run `python3 -m http.server 8000` from this directory and open http://localhost:8000.

## Hosting

This public repository uses free GitHub Pages hosting at `asharma391.github.io`. No paid domain or hosting service is required.
